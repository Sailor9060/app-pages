Harmonie2 Support

Rule-based MIDI harmonizer (AUv3 MIDI FX) for AUM and other AUv3 hosts on iPad

Getting started

Harmonie2 is a MIDI effect, not a standalone instrument — load it as a MIDI FX plug-in inside a compatible host such as AUM, then write a configuration in the plug-in's editor and press Submit to activate it.

Basic configuration syntax

One rule per line, for example:

C3 : C3 E3 G3 3/C3 : C3 C3 : //M2/1/C3 E3 G3

See the hint text inside the plug-in editor for the full syntax reference (channel switching, output routing, status variables, and filters).
